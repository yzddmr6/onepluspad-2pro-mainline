# GNOME Settings

The former standalone author-patched executable and dpkg diversion have been
retired. `erhai-settings` now supplies branding and pins for the shared Ubuntu
GNOME packages imported in `../shared-gnome/`. Sources and patches are maintained
only in the Xiaomi Pad 8 Pro integration repository; imports are byte-for-byte
copies with a commit and SHA-256 manifest. Do not add local patches here.
